# Music licensing checklist

Complete this for each actual audio track before publishing any video.

## Headlines — selection A
- [ ] Provider and exact track title recorded
- [ ] Licence / invoice / permission saved
- [ ] Video synchronization rights confirmed
- [ ] Distribution platforms and territory confirmed
- [ ] Monetization rights confirmed if needed
- [ ] Attribution wording recorded if required

## Breaking News — selection D
- [ ] Provider and exact track title recorded
- [ ] Licence / invoice / permission saved
- [ ] Video synchronization rights confirmed
- [ ] Distribution platforms and territory confirmed
- [ ] Monetization rights confirmed if needed

## Vlog — existing selection
- [ ] Existing audio file located
- [ ] Original licence / permission located
- [ ] Continued use in the intended videos confirmed

A preview, stream, or downloadable file is not automatically licensed for use in a published video. Keep proof of permission with the project.
